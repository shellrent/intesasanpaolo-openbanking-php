# Sicurezza

## Segnalare una vulnerabilità

Se trovi un problema di sicurezza in questo pacchetto **non aprire una issue pubblica**: scrivi a **sviluppo@shellrent.com**.

Nella segnalazione indica, se puoi:
- la versione del pacchetto e la versione di PHP;
- una descrizione del problema e del suo impatto;
- i passi per riprodurlo.

Ti risponderemo il prima possibile e ti terremo aggiornato sulla correzione.

## Versioni supportate

Le correzioni di sicurezza vengono rilasciate sull'ultima versione major pubblicata.

## Dati sensibili

Non includere mai in issue, pull request, log o esempi condivisi:
- credenziali (client ID e client secret) o token;
- certificati di mutua autenticazione o chiavi private;
- dati bancari reali: IBAN, CRO, nominativi, importi;
- risposte delle API di produzione non anonimizzate.
